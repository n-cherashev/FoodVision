# Ручная проверка `Sample_Video_1.mp4`

Дата проверки: 17 ноября 2026 г. Проверка выполнена через браузерный интерфейс и Docker Compose на NVIDIA GeForce RTX 5070 Ti.

## Ожидаемый результат по видео

- В начале файла примерно 6 секунд занимает красная заставка. Это не кадр зала.
- После заставки идёт статичный вид зала сверху. На 10-й секунде различимы как минимум пять столов: часть пустая, за несколькими сидят гости.
- Ожидались номера на всех устойчиво видимых столах и состояния «занят» у столов с сидящими гостями. Проходящие люди не должны менять состояние стола.

## Результат приложения

- Загрузка и анализ завершились ответом HTTP 200; длительность в ответе — 210,17 секунды.
- Система пропустила заставку и обнаружила 3 стола на 6-й секунде. Интерфейс показал исходное видео, рамки с номерами и шкалы состояний; переходы шкал позволяют перемещаться по видео.
- На 10-й секунде один из найденных столов получил состояние «занят». Два других получили «нужна проверка», включая центральный стол, за которым люди видны на кадре.
- COCO-модель пропустила по меньшей мере два других хорошо различимых стола. Это значит, что найденные рамки лежат на столах, но покрытие зала неполное.
- Итоговая шкала содержит 5, 6 и 9 интервалов по трём столам. Частые состояния «нужна проверка» сохраняют сомнительные наблюдения для ручной оценки.

## Оценка

**Частичное качество распознавания.** Обработка видео, обнаружение части столов, GPU-инференс и визуализация работают сквозным образом. Полнота обнаружения недостаточна: пропущены видимые столы. Для центрального занятого стола модель не смогла уверенно подтвердить посадку. Классификация основана на COCO-детекторе и эвристике позы; её нужно калибровать и повторно оценить на записях целевых камер. Результаты проверки подтверждают работу приложения, но сами по себе не подтверждают точность модели для производственного применения.
