# Результаты

## Параллельная нагрузка на macOS, 16 ноября 2026

Apple Silicon, 10 одновременных workers, каждый выполняет 10 проходов одних и тех же 50 кадров: всего 5 000 кадров на стек. Общий барьер синхронизирует старт workers. У каждого worker собственные ONNX-сессия, `VideoCapture` и буферы; OpenCV и ONNX Runtime используют по одному внутреннему потоку. Время загрузки моделей не входит в замер.

| Проект | Кадров | Wall-clock | Aggregate FPS | Среднее время прохода | Минимум–максимум прохода |
|---|---:|---:|---:|---:|---:|
| C# | 5 000 | 22,047 с | 226,78 | 2,163 с | 1,834–2,518 с |
| Python | 5 000 | 22,317 с | 224,04 | 2,193 с | 1,873–2,504 с |

Это измерение общей пропускной способности при конкуренции за CPU и память, а не FPS одной камеры. C# номинально быстрее на 1,2 %, что слишком мало для вывода о преимуществе стека без серии повторных нагрузочных прогонов.

## Однопоточное сравнение после обновления на macOS, 16 ноября 2026

Apple Silicon, те же видео, модель, CPU и настройки потоков; каждый проект запускался отдельно, по 10 проходов.

| Проект | Версии | Среднее время | FPS | Минимум–максимум |
|---|---|---:|---:|---:|
| Python | Python 3.14.3, ONNX Runtime 1.32.0, opencv-python 5.0.0.93, NumPy 2.5.5 | 1,036 с | 48,27 | 1,024–1,048 с |
| C# | .NET SDK 11.0.100, ONNX Runtime 1.32.0, OpenCvSharp 5.1.0.20261115 | 1,096 с | 45,63 | 1,084–1,123 с |

Версии OpenCV и подготовка кадров различаются, поэтому это не изолированный тест скорости языков. Сравнивать этот запуск с предыдущими Windows-замерами напрямую нельзя.

## Предыдущий замер

10 последовательных проходов по 50 кадрам sample.avi, YOLOv5n ONNX FP16, CPU, один поток OpenCV и ONNX Runtime. Время включает открытие и чтение файла, декодирование, resize, нормализацию и inference. Загрузка модели не включена. Postprocessing и визуализации нет.

| Проект | Среднее время | Общий FPS | Минимум–максимум |
|---|---:|---:|---:|
| Python | 3,260 с | 15,34 | 3,235–3,379 с |
| C# Release | 2,410 с | 20,75 | 2,387–2,469 с |

Это сравнение конкретных реализаций на одном компьютере. Версии ONNX Runtime отличаются: Python 1.20.1, C# 1.24.1; preprocessing тоже реализован по-разному. Поэтому результат не доказывает общее преимущество языка. Видео — первые 50 кадров [OpenCV vtest.avi](https://github.com/opencv/opencv/blob/4.x/samples/data/vtest.avi); модель [YOLOv5n](https://github.com/ultralytics/yolov5/releases/tag/v7.0).
