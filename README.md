# FoodVision

Пилотный сквозной сценарий: загрузка видео со статичной камеры, настройка столов и зон посадки, оценка состояния столов и просмотр результата вместе с исходной записью.

## Запуск на Windows с Docker Desktop и NVIDIA GPU

1. Установите Docker Desktop с поддержкой NVIDIA GPU и свежий драйвер NVIDIA.
2. Поместите подготовленную pose-модель `models/yolo11x-pose.onnx` в `models/`.
3. Скачайте COCO-модель обнаружения объектов: `powershell -ExecutionPolicy Bypass -File scripts/setup-models.ps1` (источник — [YOLO11-ONNX](https://huggingface.co/unileon-robotics/YOLO11-ONNX)).
4. Запустите `docker compose up --build`.
5. Откройте <http://localhost:8081>, выберите видео и нажмите «Найти столы».

API и health-check доступны на `http://localhost:8080` и `/health`. Модели монтируются в контейнер только для чтения. Инференс выполняется на CUDA GPU; автоматического перехода на CPU нет.

## Подготовка разметки

Сначала система ищет столы на кадрах видео до первого кадра, где сработал детектор. Она предлагает рамки столов и предварительные зоны посадки. Перед анализом пользователь может перемещать границы, добавлять и удалять столы, а также менять, добавлять и удалять зоны посадки. Если столы не найдены, их можно добавить вручную. В анализ передаётся только подтверждённая разметка.

Координаты заданы долями ширины и высоты кадра от 0 до 1. Зона посадки обозначает область, где ожидается сидящий гость. Прохожий или стоящий рядом человек сам по себе не получает состояние «гости за столом»; сомнительная поза может привести к состоянию «нужна проверка».

## Анализ и ограничения

FFmpeg декодирует видео с частотой, заданной `Analysis:SamplingFramesPerSecond` (по умолчанию один кадр в секунду). YOLO обнаруживает людей и оценивает посадку по позе. Видимый сидящий человек, чьи бёдра попадают в зону посадки, даёт состояние «гости за столом». Детектор COCO также ищет рюкзаки, сумки и чемоданы на области стола или посадки; это эвристическое состояние «гостей нет, стол занят вещами». Отсутствие этих обнаружений означает только «гостей и вещей нет», а не готовность стола к следующей посадке. Закрытый обзор или признаки недостаточной уверенности дают «нужна проверка».

Автоматическая разметка зависит от обзора камеры, освещения, масштаба и COCO-детектора, поэтому может пропускать столы или ошибаться в их границах. Pose-модель и прямоугольные зоны не всегда различают сидящего гостя и человека в необычной позе. Обнаружение вещей ограничено классами COCO (рюкзак, сумка, чемодан), может пропускать другие предметы и принимать постоянные предметы интерьера за оставленные. Пользователь должен проверить предложенные рамки и зоны. Распознавание на конкретной камере нужно отдельно оценивать; работоспособность приложения не подтверждает точность модели.

Результат содержит исходное видео, рамки столов и шкалу состояний. Нажатие на интервал шкалы перемещает воспроизведение к его началу.
